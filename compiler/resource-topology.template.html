03

The scheduling clock

Resource usage isn't only interactive — most of it fires unattended. The nightly evening chain runs feeders into the inbox, then the sweep distills them, then a chained tail lints and reports. Each routine is bound to the substrate that actually holds its resources — as of 2026-07-09 nearly everything is a local Windows task local; the only structural Cowork holdout is the monthly insights distill.

Evening chain local · nightly

Morning & monthly

Substrate rule: schedule between 10:00–24:00 (PC-on window). A routine lives where its resources do — Granola/Slack/Exa are headless-local now, so only the filesystem-less cloud distill stays on Cowork, and only graphify rebuild stays semi-attended.

05

How to read the topology

Load-bearing resources

  • obsidian + exa — the two most-shared lanes: the vault's own read/write, and the web unlock that moved the feeder chain local.
  • granola — every meeting path routes through it; authenticated headless, so meeting-sync moved local.
  • playwright — the entire brand/site build cluster's eyes; the one browser-bound lane.
  • graphify — the knowledge-graph query engine the vault-ops + self-maintenance skills lean on.

How this page is built

  • Membership + cells compile from each skill's tools: frontmatter.
  • Vendored skills (byte-for-byte upstream) contribute via compiler/resource-sidecar.json.
  • Regenerate: node "agent-os/compiler/build-resource-map.mjs" → resource-map.json + this HTML.
  • Add a connector to a skill → edit its tools:, re-run, the map updates.
